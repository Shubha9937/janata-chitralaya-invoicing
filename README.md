# Janata Chitralaya — GST Invoicing & Rental Management

A mobile-friendly, secure web application designed for **Janata Chitralaya** (Odisha's premier cultural costume and theatrical attire house) to streamline daily in-store billing, GST-compliant tax invoicing, costume rental deposit tracking, and customer records.

---

## 📌 Project Overview

This application serves as the dedicated billing and administrative counter tool across all 3 Janata Chitralaya branches in Bhubaneswar:
1. **Unit-8 Flagship:** Shop No. KXS-15, Kalyani Market Complex, Unit-8, Bhubaneswar
2. **Patia / Nandan Vihar:** Near Subhadra Apartment, Nandankanan Road, Patia
3. **Nuagaon Cultural Hub:** Nuagaon Main Road, Near Indian Oil Petrol Pump, Nuagaon

---

## 🎯 Key Planned Features

### 1. Mobile-First Invoicing Interface
- Fast, touch-optimized billing counter UI designed for smartphone and tablet operation.
- Quick customer lookup and repeat client autofill (schools, drama troupes, dance academies, photographers).

### 2. GST-Compliant Tax Invoices
- Automatic calculation of applicable GST rates (CGST + SGST / IGST).
- Standard HSN / SAC code classification for costume rentals and stage artistry services.
- Clean printable invoice format (thermal print receipt and standard A4/A5 PDF generation).

### 3. Costume Rental Lifecycle Management
- **Security Deposit Tracking:** Record refundable caution deposits and rental security amounts.
- **Return Due Date Tracker:** Scheduled return dates, late return fee calculation, and damage assessment.
- **Item Return Clearance:** One-click deposit settlement and return clearance receipts.

### 4. Direct Customer WhatsApp Dispatch
- Instant 1-tap PDF invoice and receipt dispatch directly to customer's WhatsApp number.
- Automated reminder messages for costume returns.

### 5. Multi-Branch Support & Reporting
- Branch switcher with customized branch header, contact numbers, and GSTIN details.
- Daily register summary (cash, UPI, rental counts, and outstanding returns).

## 🛠️ Tech Stack (Planned)
- **Frontend / Core:** Lightweight, responsive modern web interface (HTML5, Vanilla CSS / Tailwind, Vanilla JS).
- **Storage / Backend:** Offline-resilient local storage or lightweight API / serverless backend.
